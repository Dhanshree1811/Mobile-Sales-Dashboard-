# Mobile-Sales-Dashboard-
Interactive Power BI dashboard analyzing mobile sales performance, customer trends, product performance and key business metrics.
## Project Overview

The goal of this project was to turn raw mobile sales data into an interactive dashboard that makes it easier to understand overall sales performance and identify important business trends.

I used Power BI to clean and transform the data, create calculations and build interactive visualizations.

## Tools Used

- Power BI
- Power Query
- DAX
- Excel

## Key Analysis

The dashboard focuses on:

- Total sales performance
- Quantity sold
- Revenue trends
- Product performance
- Customer trends
- Sales by different categories
- Monthly sales patterns
